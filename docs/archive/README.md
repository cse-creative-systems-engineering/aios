# Archived Documentation

This directory holds historical notes and superseded plans. Archived documents
are retained for context, but they are not current implementation instructions.

## Categories

- `context/` contains dated grounding snapshots and session notes.
- `research/` contains investigations that led to current decisions.
- `superseded/` contains plans or specifications replaced by accepted ADRs or
  newer milestone documents.

Current work starts at `PROJECT_GROUNDING.md`, then the latest snapshot and the
active milestone or decision document for the task.
