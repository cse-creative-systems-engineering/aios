# Documentation Entry Point

Begin with the repository-level [`PROJECT_GROUNDING.md`](../PROJECT_GROUNDING.md)
and its linked dated snapshot before reading this directory in full.

The grounding snapshot is the fast context index. The files in this directory
remain the detailed source of truth for architecture, requirements, security,
protocols, milestones, decisions, and specialist contracts.

For current progress, read [`doc-progress.md`](doc-progress.md). For active
implementation work, also check [`implementation-roadmap.md`](implementation-roadmap.md)
and the relevant module or decision document.
